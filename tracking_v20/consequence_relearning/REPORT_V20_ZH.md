## 检索复查和失败后的接触

random：147,456 次访问引用 123,722 条历史事件；同一事件在后续查询轮再次访问 23,734 次，涉及 21,108 条事件。访问前权重小于 0.25 的低权重访问 68,311 次；同一轮重复访问 0 次单列。
random：碰撞新连续段 9,461 个；失败发生时已有完整后续 32 步场景预算的段 9,077 个，其中同一身体、场景和目标内后来首次触达 2,439 个（26.87%），触达中的安全标记 0 个。发生碰撞的同一步已经触达 97 个，不混入后续首次触达分母。
random：碰撞后不足 32 步的短窗口另有 281 个，其中后来首次触达 34 个；成功与失败均不进入主比例。
random：受击新连续段 9,290 个；失败发生时已有完整后续 32 步场景预算的段 9,026 个，其中同一身体、场景和目标内后来首次触达 2,767 个（30.66%），触达中的安全标记 1,818 个。发生受击的同一步已经触达 0 个，不混入后续首次触达分母。
random：受击后不足 32 步的短窗口另有 249 个，其中后来首次触达 30 个；成功与失败均不进入主比例。
retrieval：147,456 次访问引用 122,873 条历史事件；同一事件在后续查询轮再次访问 24,583 次，涉及 20,852 条事件。访问前权重小于 0.25 的低权重访问 33,621 次；同一轮重复访问 0 次单列。
retrieval：碰撞新连续段 10,835 个；失败发生时已有完整后续 32 步场景预算的段 10,379 个，其中同一身体、场景和目标内后来首次触达 2,664 个（25.67%），触达中的安全标记 0 个。发生碰撞的同一步已经触达 94 个，不混入后续首次触达分母。
retrieval：碰撞后不足 32 步的短窗口另有 351 个，其中后来首次触达 51 个；成功与失败均不进入主比例。
retrieval：受击新连续段 9,885 个；失败发生时已有完整后续 32 步场景预算的段 9,564 个，其中同一身体、场景和目标内后来首次触达 2,739 个（28.64%），触达中的安全标记 1,705 个。发生受击的同一步已经触达 0 个，不混入后续首次触达分母。
retrieval：受击后不足 32 步的短窗口另有 315 个，其中后来首次触达 50 个；成功与失败均不进入主比例。

低权重事件始终允许访问，0.25 阈值只是离线计数组；这些记录不表示关闭后重开，也不是从冷库恢复。

安全触达定义是成功触达且上次触达以来没有碰撞。碰撞标记持续到成功触达，因此碰撞后同一目标的安全触达按定义必为零，不能用这个零值评价恢复能力。受击标记只代表当前步，受击后同一目标仍可能安全触达。碰撞和受击连续段分开统计，两类允许重叠；本小节次要跟踪指标使用后来首次成功触达，窗口截断在首次触达或重置。

再次引用历史事件表示复查；不代表环境中的新相似遭遇，也不证明检索导致行为恢复。失败后触达统计同样只是实际后续事件，不能单独归因于检索。

## 结论范围

本轮检验有界事件目录、真实执行动作后果学习和有限引导后的实际行为差异。单个共享初始化、两条实践轨迹、已反复查看的开发场景，不支持确认性显著性判断。后果预测受当前行为轨迹影响，未执行动作没有已验证反事实标签。这些记录不证明形成了生物层级结构或真实生物动力学。
