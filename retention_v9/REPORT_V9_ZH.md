# V9：反复实践中的淡出、重学和可变保留

日期：2026-10-12。

## 修正后的研究对象

不把细节永久划为有用或无用。某次经历没有体现某条细节的作用，不代表
它以后不值得保留。需要在反复实践中允许：

**观察与学习 -> 细节淡出 -> 后续预测或行动失误 -> 查回原始信息 ->
再次学习 -> 调整保留程度 -> 继续实践。**

分级随经历升降，没有一劳永逸的价值结论。
这个修正已记录到上级目录的 `RETENTION_PRINCIPLE_20261012_ZH.md`，
并约束后续实验。旧报告中的局部“作用为零”不再表述成细节永久无用。

## 本轮实际实现

复用 V8 的三个既有检查点，不挑选成绩最好的种子。新建独立物理经历池，
每个动作真实改变后续位置和速度。目标每八步改变，状态条件每十六步改变，
会反复经历先前出现过的条件。

模型每步先预测、选择并执行一个动作，再接收该动作的实际位置、速度和
接触反馈，用反向传播更新。其他未执行动作的真实结果只供评分使用，
不交给学习器。

活跃引用最多四条，每次读取两条。引用淡出时原始图像从当前输入缓存中
移除，仍保存在 SQLite；重学时实际查数据库。每次过去的身体状态、
执行动作、实际后果和原预测也存入各运行的 `practice.sqlite`。

信息贡献根据已发生的物理反馈估计：遗漏该信息时的预测损失，
减去当前预测损失。积累、衰减、竞争和重学共同改变保留状态。
模型不接收“这是重要细节”的标签。

四种策略都继续更新模型权重，区别在目录：

- 固定目录：保持初始引用，不再检索。
- 定期回访：每八步重新读档、学习和整理。
- 反复重学：观察到预测错误升高后回访，并保留最长十六步的探索间隔。
- 重学加巩固：反复出现正贡献会延长引用寿命；贡献证据继续衰减。

寿命和衰减公式是明确的实验设计，不是已经证明的自然规律。
本轮只检验这种过程能否工作，没有证明它是最佳分级算法。

## 确认结果

开发四组；独立确认二十四组。每个条件三个初始化/环境种子，各有
六十四个并行世界，比较一百二十八步和五百一十二步实践。

评分是实际物理代价：执行动作距最优代价不超过 0.02 就通过，允许多个
正确动作。每步都在反馈和权重更新前评分，属于边实践边学习的表现，
不是冻结模型准确率，也不是与原模型的一致率。

五百一十二步，三个种子平均：

| 目录策略 | 全程动作成功率 | 最后32步成功率 | 回访比例 | 平均每步活跃引用 |
| --- | ---: | ---: | ---: | ---: |
| 固定 | 90.08% | 96.40% | 0% | 4.00 |
| 定期回访 | 91.23% | 98.01% | 12.50% | 3.26 |
| 反复重学 | 93.05% | 98.96% | 12.32% | 2.76 |
| 重学加巩固 | 93.20% | 99.33% | 11.40% | 2.69 |

巩固相对普通重学的全程差别只有约 0.16 个百分点，不能说有明确的普遍优势。
三个配对种子中两个提高、一个略降。它的更清楚变化是减少反复丢失和回访。

只实践一百二十八步时，全程成功率分别为 80.58%、82.39%、85.12%、84.95%。
巩固的好处不是从一开始就出现；继续学习的时间和经历量仍然影响结果。

## 同一细节确实反复淡出和返回

五百一十二步，每个六十四世界组的平均次数：

| 策略 | 细节引用淡出 | 曾淡出的细节再次返回 |
| --- | ---: | ---: |
| 定期回访 | 1,199.3 | 1,180.7 |
| 反复重学 | 918.3 | 894.3 |
| 重学加巩固 | 629.7 | 605.7 |

巩固相对普通重学减少约 31% 的细节引用淡出，仍保留大量再学习过程。
三个种子中，巩固组分别有 40、42、61 个世界发生至少两次细节返回；
单个世界最多分别返回 31、29、27 次。没有把第一次的保留决定永久固定。

这里测量的是原始引用的淡出和返回。信息可能仍部分保存在参数、身体
状态或目录结构中，因此这些次数不能称为彻底擦除信息的次数。

## 检查实践后是否只记住旧经历

用从未进入实践流的新图像和新身体样本，冻结权重进行独立前后测。
前后测均使用统一的新鲜引用条件，不使用实践中的旧目录。

| 策略 | 实践前新样本成功率 | 512步后新样本成功率 |
| --- | ---: | ---: |
| 固定 | 79.95% | 95.70% |
| 定期回访 | 79.95% | 98.26% |
| 反复重学 | 79.95% | 99.00% |
| 重学加巩固 | 79.95% | 99.39% |

新样本的左墙布局，四组实践后分别为 96.44%、98.18%、98.87%、99.13%。
**这不是未见布局泛化**：左右布局已经在本轮实践中出现。
这里支持的是经验后的新样本迁移，不能拿它消除 V8 的零样本布局失败。

## 反例与限制

1. 种子差异很大。巩固组三个全程成功率为 95.32%、99.28%、85.00%。
   三组环境和初始化一起改变，尚不能分离这两个来源，也未做显著性声明。
2. 一次回访未必立刻改善预测。种子37的定期、重学和巩固组，重新读取后的
   平均损失反而升高。不能预设“查回来就对了”，需要继续用实践检验。
3. 定期回访虽增加成功率，平均后悔值却略差于固定目录：
   0.02071 对 0.01899。重学为 0.01617，巩固为 0.01488。
   离散成功率和错误严重程度要一起看。
4. 检索组有额外的回放和价值训练，计算预算不同。当前对照不能把全部改善
   归给目录本身，需要后续增加等额辅助学习的对照。
5. 预测误差可能来自模型未学会、环境变化或信息缺失。误差触发器尚不能
   完美区分原因。检索不成功也会被记录，不事先假定每个错误都是遗忘造成的。
6. 视觉原始记录仍是每个世界开始时的历史；连续变化的是身体、目标和条件。
   尚未实现视觉世界持续生成全新事件、跨生命史扩大的记忆库。
7. 本轮身体状态由程序输入，模型规模很小；它是集中式计算上的功能模拟，
   不是完整果蝇脑，也没有完成 Qwen 参数级精度调度。
8. 所有记录的元数据仍存在，扫描数据库也仍为整段扫描。没有声称已实现
   硬件加速，或已找到不需人为设定参数的最优遗忘公式。

## 审计和存储

八项契约检查通过。独立审计重算了 491,520 次转移，核对物理状态、接触、
动作代价、得分、身体连续性和学习次序。该数量包含长短预算共享的前缀，
不能当成同样数量的独立经历。

另核对 7,656 次目录转移，短长实验前128步一致，数据 ID 分离，源码、
依赖和初始化检查点哈希一致。SQLite 完整性及实际后果记录通过。
两个冻结检查点的前后测独立重算一致，诊断期间没有更新权重。

审计脚本曾因反复解压轨迹而缓慢，已改为一次读取后核对；只重新运行审计，
没有重复训练或改变结果。训练和验证进程均已退出。

V9 全部文件约135 MiB，位于 E 盘，没有下载新权重。
原始观察、实践经历、模型、失败记录和逐步证据都保留。

还是环境规律已经变化。加入相同辅助学习预算的对照，并让新视觉事件
持续进入数据库。任何细节都不预先判定为永久无用，保留分级继续接受
后来实践的修正。
