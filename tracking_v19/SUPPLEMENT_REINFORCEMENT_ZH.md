# 补充：遗忘、重复学习与预测能否形成分层

记录日期：2026-10-14。检索发生在 V19 训练启动之后。本笔记仅作理论对照，不追溯修改已冻结的代码、配置、指标或实验假设；未开展论文复现。

## 理论支持及边界

“遗忘与反复纠错能够形成保留强弱差异”有直接理论依据；“必然形成有用的具身层级”仍是本项目待验证的推断。

RPF [1] 的独立特征模型为每种模式设一个标量强度：独立 Bernoulli 暴露、有限固定目标、相容更新、更新后乘性衰减。在 `0 < d < 1`、`0 < eta*p < 1` 下，其期望强度收敛为：

```text
E[w_infinity] = ((1-d)*eta*p)/(d+(1-d)*eta*p) * theta
```

因此重复支持可以抵抗遗忘，但这是期望值结论。共享参数定理进一步假设线性预测、平方损失、固定二阶矩和各坐标相同衰减，得到按协方差特征值过滤的结果。MDL 解释还依赖小步长及范数/编码近似，不能直接套用为非线性具身网络的定理。[1]

Go-CLS [2] 用带噪线性教师、线性学生与稀疏 Hopfield 笔记系统建立主要可解析模型。其原则是按未来泛化收益调节巩固量，避免把有限经历中的不可预测成分过度写入共享权重；未巩固的经历仍可留在笔记系统。它不是“先忘细节”的规则，也未确定真实大脑如何估计可预测性。[2]

两者可作互补解释：RPF 描述什么在持续衰减中留下，Go-CLS 讨论什么值得转成可迁移的预测关系。这不等于两者已证明本项目架构有效。

## 频率不等于重要性

RPF 明确允许重复偏差留下、罕见有用事实丢失；其一般支持度还包含相容更新和可恢复性，不只是次数。[1] 所以高频背景可能压过低频危险。项目应让实际后果、后续预测改善和重复实践共同修订回放与保留，不能把低频、低置信度直接当作删除理由。危险经历保留可恢复原件；也不能永久手写哪些细节“必定有用”。

预测提供纠错信号，但仅降低预测误差不足以证明学会有用关系；模型可能只改善常见背景预测，仍然漏掉攻击。

## 支持具身层级形成所需的过程证据

以下是未来分析或实验建议，不是对本轮事后新增的成功标准：

1. **可修订保留。** 同一线索经历弱化、行为失败、再次学习和重新保留；记录每次暴露、回放、门控变化及实际后果，不能只看最后权重。
2. **频率控制。** 在相近暴露预算下，罕见危险与常见背景的学习轨迹可区分；排除只记住次数最多或最近的内容。
3. **跨场景复用。** 新障碍、目标运动与攻击组合中，已有关系加快适应；逐场景报告受击、碰撞、接触和预测变化，避免平均分掩盖退步。
4. **时间与功能分化。** 某些表示快速响应局部变化，另一些跨时间、跨场景稳定；仅出现不同门值或聚类，不足以称为层级。
5. **干预证据。** 在后续预先规定的短暂干预中，弱化候选共享表示应影响多个相关场景；弱化局部细节应产生较局部影响，恢复后能力可回升。与等量随机干预比较，区分真正分工与单纯容量损失。

RPF 名称及基本理论归原作者。本项目不声称首创“重复强化加持续遗忘”，也不重跑其标量或合成分类实验；后续问题是这些机制如何在闭环感知、行动和可恢复经历中形成可检验的分工。
