# 多场景共同学习：文献核查与V13方向修正

日期：2026-10-13。状态：调研完成，旧方案撤回，没有执行V13实验。
用户强调“不断尝试后形成更优选择”，目标是会学习的具身机器人核心框架。
本次仅核对公开原始资料，没有下载数据集、模型或复现论文实验。

## 1. 需要修正的判断

有明确证据支持把丰富的多场景共同学习作为主线。不能用少数环境的反复
再适应代替跨场景能力发展。原V13把A-B-A-B当作主要课程，且没有独立
跨任务评价，偏离了用户的研究目标；未等文献核查完整就指定三组和预算过早。

但要限定结论：顺序训练不必然过拟合；联合训练不必然产生泛化。
顺序任务引发的旧能力丢失通常讨论为遗忘；熟悉场景表现很好而新场景差
才是这里要防止的泛化缺口。两者可以同时发生，机制和诊断不同。[1][4][7]

用户未给出其所指实验的名称，无法确认是否就是下面的某篇。
MT-Opt和XLand与“跨场景共享经历、逐步发展更广能力”最直接相关；
它们并不构成“此前顺序方法全部失败”的历史证明。[2][3]

## 2. 直接相关的已有证据

以下只概括核实的部分，不把一篇论文当作普遍保证。

| 工作 | 核实的证据 | 对本项目的启示与边界 |
| --- | --- | --- |
| Procgen，ICML 2020 [1] | 第3节改变训练关卡数量并测试其他关卡；小训练集明显过拟合。第3.2节另有固定关卡序列诊断。 | 需要环境分布的多样性及训练/评价分离。其游戏与我们的物理任务不同；固定序列诊断不等同本项目A-B-A-B。 |
| XLand，2021 [2] | 第5节结合丰富任务空间、动态任务生成和多代训练；第6.2节有移除动态生成等组件的对照。 | 借用共同经验覆盖、动态难度和全程能力分布视角；不能把效果归结为“同时多开几个环境”。 |
| MT-Opt，CoRL 2021，论文集2022 [3] | 7个机器人采集12类真实任务，联合共享探索、经历和表示；报告结构相近新任务的迁移及新技能学习。 | 比单一小型反转任务更符合具身目标。任务通过人为提供的期望结果样例定义；不能据此认定我们的局部学习和目录机制已经被验证。 |
| Meta-World，CoRL 2019，论文集2020 [4] | 明确区分共同训练和新任务适应。第5节MT10中多头SAC约85%成功率，单头SAC约40%；MT50中多头SAC约40%，联合学习效果受架构和任务规模影响。 | 场景应不同但有共享结构；MT评价本身不检验新任务泛化，不能把共同训练平均分直接作为迁移证据。 |
| Dynamics Randomization，ICRA 2018 [5] | 改变仿真的物理参数，使用经历历史识别动力学，在推物任务上验证向真实机器人迁移。 | 保持物理变化可从传感历史推断，不能每步无依据地随机改规则。其critic使用真实动力学参数，我们不能照搬这项特权。 |
| Gradient Surgery / PCGrad，NeurIPS 2020 [6] | 分析并处理多任务更新中的梯度冲突、幅度差异与曲率问题。 | 混合经验也可能彼此干扰；优先诊断局部模块的跨场景收益，不预设简单平均就有效，也不立即照搬PCGrad。 |
| Continual World，NeurIPS 2021 [7] | 区分遗忘和前向迁移；CW20表1中PackNet平均表现0.80，联合训练0.51，加入PopArt为0.65。 | 是“同时训练总是更好”的条件性反例，不能据此恢复旧方案。该设置依赖任务边界和身份，PackNet还需预知序列长度；主要不测试未见任务泛化。 |
| CLEAR，NeurIPS 2019 [8] | 结合新经历的on-policy学习与旧经历的off-policy replay/行为克隆，缓解遗忘并保留学习新知识的能力。 | 经验混合和回放本身已有方法；本项目若用它们，仅作为组件，不作为新贡献。 |
| IMGEP，JMLR 2022 [9] | 多目标探索，用为一个目标取得的信息促进其他目标，实验含真实机器人。 | “逐步学会更优选择”可以用跨目标能力发展观察；不把已有自动课程和学习进步指标重新包装。 |

补充：Open X-Embodiment / RT-X也提供跨机器人经验产生正迁移的证据，
但它使用汇集的机器人轨迹训练策略，不能据此声称机器人会在部署中
自主持续试错。本轮只核对作者项目页，未获取论文PDF正文；
仅用作机器人多源经历的补充，不作为本轮核心算法。[10]

## 3. “同时学习”的可实现含义

建议采用“多个相关场景共同训练同一个学习系统”，不是要求一个身体
同一物理时刻位于多个地点，也不是所有底层参数同时激活：

1. 多个仿真身体分别经历完整、连续的感知-行动-后果序列。
2. 学习批次或经验重放持续覆盖不同场景，序列内部时序不被打乱。
3. 共享可复用的预测与选择参数；各身体的即时状态和事件身份相互隔离。
4. 通过自身真实经历形成可修订目录。其他身体的经验可以用于共同训练，
   不能不经区分地作为当前身体刚刚观察到的事实输入。
5. 继续使用局部更新，不为实现共同学习强加跨全系统的端到端梯度。

这是本项目的设计推论，借鉴[2][3][8]，不是这些论文已经验证的同款架构。
“有64个并行世界”本身不够：64个世界如果都在同一阶段遵循同一套
狭窄规则，主要增加的是样本数量，不一定扩大技能或关系覆盖。

从已有证据推到本项目，最关键的是把“经历更多”与“经历更多种关系”
分开：反复经历同一关联，可以使熟悉场景上的估计更稳定，却未必排除
另一套只在新场景才暴露的错误规则。共同训练提供打破这些快捷关联的
机会；只有关系覆盖充分、共享结构可学习且任务干扰可控时，这个机会
才可能形成泛化。[1][4][6] 这是设计推论，不是任意混合都有效的定理。

## 4. 原V13草案的具体问题

根据本地PROTOCOL.md和未执行测试草稿判断，不是实验结果：

- 所有世界同步经历同一A-B-A-B阶段，主要检验反转和回访，缺少持续多场景覆盖。
- 风险0.35/0.95与两种线索映射一一对应。即使风险是合法传感输入，
  模型也可能只记住这项快捷关联；没有设计打破它的组合。
- 全16对参数都进入学习，却取消独立未见组合观察。在线错误下降可以
  表示熟悉环境进步，但不能排除在该小集合上的专门化。
- 仍是相同的一维控制任务，换惯性、外力或规则不等于增加了新的行为结构。
- 同时改变选择层级、探索分布、反馈中心化和跨度，因果解释不够集中。
- 以本阶段最终表现反推“恢复阈值”只描述再适应，无法独立证实普遍学习能力。

这些问题没有被训练数字解决；不再为旧草案投入训练。
旧文件保留并标为withdrawn，便于追踪设计为什么被否决。

## 5. 修订方向：先定义分布，再确定算法差异

以下是研究约束，不是已冻结的实施方案或运行许可。

| 维度 | 下一版应回答的设计问题 |
| --- | --- |
| 共享结构 | 哪些运动、接触、物体和目标关系可在多个场景复用？ |
| 场景多样性 | 改变布局、对象属性、目标关系、身体状态、观察可靠性，而不是只换两个规则标签。 |
| 时间 | 各世界内部连续且自洽；跨世界同时覆盖相关变化，不规定全体一起进入A或B。 |
| 目录价值 | 同一细节在不同处境有不同价值；丢失、查回和重学的后果可让分级反复改变。 |
| 混合比例 | 避免全部资源被容易任务或高回报量纲占据；记录覆盖，不先拟定大量比例扫描。 |
| 未见关系 | 留出独立组合或场景结构；各因素边际覆盖充分，避免测试中两条线索完全相关。 |
| 算法贡献 | 多任务、回放、动态课程都已有。只挑一个可分辨的目录/局部学习改动，而非一次叠加全部机制。 |

不再用“顺序学习对比同时学习”作为新算法成果，不重跑本文论文的整套基准。
混合多场景可以直接作为工作条件，必要对照只用于辨认本项目的新机制。
是否扩大参数取决于覆盖与干扰分析；不把容量、训练量和算法同时变化后归因于算法。

## 6. 如何保留“看过程”，又不把过拟合当进步

核心观察：随着共同经历积累，未学过的新处境上是否越来越容易做出更优选择。
多场景平均成绩仅为一项，不能掩盖某类场景持续恶化。

建议在整个实践期间保留三条相互区分的记录：

1. 当前经历：在反馈更新前保存预测和行动后果，观察同类困难是否逐步减少。
2. 新组合首次接触：记录任何该场景反馈到来前的表现；一旦参与学习就不能
   再称其为未见。用预先划分、尚未用于学习的后续组合继续观察发展过程。
3. 新处境中的学习曲线：首次接触后允许实践反馈，记录少量经历后的改善与代价。
   它反映适应速度，与不学习的新组合能力分开；不回写先前成绩。

同时跟踪原始细节的淡出、查回、重学和重新分级记录。
选择次数更少、分布更尖锐、某个参数组独占，不直接算进步。
样本量、场景覆盖、学习更新次数和计算/检索费用分别记录。
若只看到熟悉场景进步、新处境没有改善，就明确报告局部熟练，没有证据支持迁移。

这些过程记录不是“回到最终答案比赛”：它们用于检验过程中的进步
是否越过熟悉场景边界。不预设每一步单调改善，也不为好看的曲线改种子。
