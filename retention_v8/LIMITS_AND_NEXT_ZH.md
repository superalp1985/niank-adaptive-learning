# 当前边界与下一步

日期：2026-10-12。在确认训练结束前记录，不以最终集继续修改本轮算法。

## 当前算法可验证的范围

本轮只检验一条功能链：

观察与当前身体状态 -> 预测物理后果 -> 从实际损失贡献学习信息价值 ->
有限活跃引用 -> 状态变化后查数据库 -> 再作物理预测与动作选择。

这与用户提出的“事实训练与预测双向调整到实用”相符，但不是完整实现。
模型仍为同步矩阵运算；没有真实脑动力学或生物同时活动的实现。
它也不是果蝇全脑学习模型：本轮使用新建的小型可训练视觉和身体网络，
而非原始连接组脉冲动力学。Qwen 参数级精度路由未在本轮推进。

## 三个容易误解的指标

1. 动作成功率高不保证物理预测正确。身体分布本身能提供动作线索，
   所以必须同时检查固定身体下的细节翻转响应。
2. 活跃目录没有某条细节，不保证已经忘掉该信息。目录选择、保留与否、
   其他记录的软权重都可能间接编码它。冻结目录诊断将分开检查。
3. 本轮引用数量少不等于真实计算量少。全候选编码、排序、辅助回放、
   条件遗漏解码和完整数据库扫描都需计成本。

## 当前未知

- 重要性分数依赖模型自己的解码器。解码器犯错可能让价值估计也犯错。
- 0.005 成本和各损失系数是公开的研究设置，尚未自适应学到。
- 物理结果差值目标可能挤占动作学习，尤其在低训练量阶段。
- 多个优化种子仍共享同一训练环境池和最终环境池，不能当成多个独立世界。
- 左右布局与观察纹理迁移只能检验局部变化，不能代表广泛泛化。
- 当前是提前生成的经历与物理标签，不是完整长期闭环具身生命史。

## 下一轮独立实验建议

1. 用新环境种子扩展到多步闭环：动作改变身体状态，后续观察由环境产生。
2. 区分实际传感器经历、模型预测、预测误差和训练后权重；每次预测先评分，
   再反馈学习。最终冻结诊断仍须保留。
3. 学习目标权重随实际误差和训练阶段变化，检验能否消除低训练量阶段的
   动作下降。保留固定权重对照，不假定自适应必然更好。
4. 让检索触发由预测不确定性或状态改变的价值来决定；减少目前无条件
   完整扫描。检索成功、失败、读取成本均计分。
5. 为“保持原样、概念化压缩、只留目录、数据库检索”设置不同记忆状态；
   先测试功能，再研究符合 GPU/内存布局的具体存放方式。
6. 对环境变化加入真正的未见组合，避免只记住两个风险状态。

上述为新开发轮的待验证假设，不是本轮已经完成或证实的能力。
